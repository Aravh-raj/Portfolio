# Aravh Raj — Personal Portfolio

A high-performance, dark-themed personal portfolio landing page for **Aravh Raj** — Full-Stack Developer & AI-Powered Product Builder based in Kolkata, India. Built with modern web standards, fluid typography, interactive physics, and an architectural engineering focus.

---

## 🚀 Built With

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Tooling**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Motion & Physics**: [Framer Motion 12](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: [Kanit](https://fonts.google.com/specimen/Kanit) (Google Fonts)

---

## ✨ Features

- **Fluid Massive Typography**: Responsive `clamp()` typography scaling gracefully from mobile to ultra-wide displays.
- **Interactive Magnetic Physics**: Centerpiece terminal telemetry visual with dynamic mouse-following attraction using custom `Magnet` component.
- **Dual-Row Parallax Marquee**: Two opposing rows of verified technical cards moving in real-time with passive scroll calculations.
- **Scroll-Driven Character Opacity**: Narrative paragraph with character-by-character reveal (`useScroll` and `useTransform`).
- **High-Contrast Competency Shift**: Smooth transition into a crisp light section detailing core technical areas.
- **Sticky Stacking Project Cards**: Smooth scroll-linked scaling card stack highlighting system architectures.
- **Zero Fabricated Claims**: Meticulously audited for authentic technical descriptions with no unverified benchmark numbers or synthetic statistics.

## 💻 Local Development

### Prerequisites
- Node.js (v18 or higher recommended)
- npm (v9 or higher)

### Setup
```bash
# Clone the repository
git clone https://github.com/Aravhraj-stack/aravh-raj-portfolio.git

# Navigate to project directory
cd aravh-raj-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be running at `http://localhost:3000/`.

### Build
```bash
# Typecheck and build production bundle
npm run build

# Preview production build locally
npm run preview
```
